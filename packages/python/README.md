# Python SDK status

A Python SDK is planned for this directory. No Python client, PyPI distribution
or Python package version is implemented or published yet.

The current [Node.js SDK](../node/README.md) supports JavaScript and TypeScript.
When Python is implemented, it will have its own `pyproject.toml`, source, tests,
changelog and PyPI release workflow, with independent versions and
`python-v<version>` tags. A Node release will not imply a Python release.
